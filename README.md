# Yonda!

手に取った本の記録と本棚のアプリ（スマホ向けWebアプリ）。

## 機能
- 本の登録：書影・タイトル・作者（ISBNやタイトルで検索して自動入力／書影は写真でもOK）
- 手に取ったときの気持ち・読んだあとの感想（★評価つき）
- 手に入れた方法：購入／図書館／レンタル／借りた／もらった／その他
- 今の状況：読み始めてない／読んでいる／積んどく中／読み終わり／むずかしかった
- 「むずかしかった」本は、ジャンルの棚とは別の「むずかしかったボックス」にしまわれます
- ジャンル別の本棚（ジャンルは設定から追加・並べ替え・名前変更できます）
- 気になったページを写メ＋ページ番号＋メモで記録
- JSONでバックアップ・読み込み

データはブラウザ内（IndexedDB）に保存され、外部には送信されません。
（本の検索時だけ openBD / Google Books に ISBN・タイトルを問い合わせます）

## パソコンで動かす
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
→ http://localhost:5173/ を開く

## スマホで使うには
カメラやホーム画面への追加を使うには HTTPS で公開する必要があります。
GitHub Pages / Netlify / Cloudflare Pages などにこのフォルダをそのまま置けば動きます。
